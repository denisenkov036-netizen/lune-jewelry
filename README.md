# lune-jewelry
Назва продукту: LUNÉ. Покупці ювелірних прикрас отримують зручний каталог із детальною інформацією про вироби та можливістю переглядати їх у 3D. На відміну від Kochut (kochut.org), який використовує переважно фото та відео, LUNÉ дозволяє обертати й розглядати прикраси з різних ракурсів. На відміну від Blue Nile (bluenile.com), LUNÉ робить акцент на візуальній презентації власних колекцій та інтерактивних 3D-моделях зі зміною матеріалів. На відміну від SOVA (sovajewels.com), LUNÉ пропонує більш інтерактивну подачу прикрас у форматі 3D.
