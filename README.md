# lune-jewelry
Назва продукту: LUNÉ. Покупці ювелірних прикрас, які хочуть швидко знайти та підібрати прикрасу за матеріалом, типом і дизайном, отримують зручний каталог із детальною інформацією про вироби замість пошуку товарів у соцмережах і розрізнених каталогах. Серед аналогів бренд Kochut (kochut.org), який використовує фотографії та відеоматеріали для презентації прикрас, тоді як LUNÉ відрізняється використанням інтерактивних 3D-моделей, завдяки яким користувач може самостійно обертати прикрасу та розглядати її з різних ракурсів у браузері. Міжнародний магазин Blue Nile (bluenile.com) пропонує інструменти для вибору та налаштування ювелірних виробів, тоді як LUNÉ відрізняється акцентом на візуальній презентації власних колекцій та інтерактивній взаємодії з 3D-моделлю, зокрема можливістю змінювати матеріали. На відміну від українського бренду SOVA (sovajewels.com), який представляє великий асортимент у форматі стандартних карток товарів, LUNÉ відрізняється більш інтерактивною подачею у форматі 3D, де для окремих моделей можна перемикати матеріали без перезавантаження сторінки.
